# Agentic Memory

This directory stores persistent AI agent memory for long tasks (6+ hours).

## Structure

For each long-running task, create a subdirectory:

```
.ai/memory/
├── feature-name/
│   ├── progress.md      # Current status
│   ├── decisions.md     # Key decisions log
│   └── learnings.md     # What worked/didn't work
```

See GUIDE.md#agentic-memory-for-long-tasks for complete workflow.
