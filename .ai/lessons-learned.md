## How to Use This File

**For AI Agents:**
- Read this file before starting work on similar features
- Learn from past mistakes to avoid repeating them
- Follow "What Worked" patterns for proven success
- Avoid all items marked with ❌

**For Developers:**
- Update after completing significant features
- Document both successes and failures
- Focus on non-obvious learnings
- Include enough context for future understanding

**Maintenance:**
- Review monthly for relevance
- Archive outdated entries to separate file
- Keep file focused (< 500 lines)
- Prioritize high-impact learnings
